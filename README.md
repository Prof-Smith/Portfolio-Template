# Professional Evidence Portfolio

A static HTML/CSS portfolio mockup designed for GitHub Pages.

## Publish
1. Create a new public GitHub repository.
2. Upload the contents of this package to the repository root.
3. Open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

## Customize
- Replace `assets/profile.jpg` with the student's image.
- Replace `assets/Zachary-Smith-CV.docx` with the student's resume and update both links in `index.html`.
- Replace placeholder `#` links and `YOUR.EMAIL@example.com`.
- Edit project, publication, video, and presentation cards in `index.html`.
- Change the color variables at the top of `styles.css`.

The page is responsive, keyboard-accessible, printable, and requires no framework.
