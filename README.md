# World-Class Professional Evidence Portfolio

## Deploy to GitHub Pages
1. Extract this package.
2. Upload **all extracted files** to the repository root, replacing the previous versions.
3. Confirm that `index.html`, `portfolio-v4.css`, `.nojekyll`, and the `assets` folder appear at the top level.
4. Commit to `main`. GitHub Pages will redeploy the site.

## Why the stylesheet has a new name
`portfolio-v4.css` is intentionally versioned so the browser does not reuse an older cached stylesheet.

## Customize
Replace placeholder `#` links with live projects, slides, repositories, and LinkedIn. Edit the email address if needed.
